# ⚔️ 오딧세이: 일곱 성채

전쟁의 길, 일곱 번의 판단.

패잔병 천 명을 이끌고 본국으로 귀환하는 사령관이 되어,
일곱 개의 성채를 통과하며 매번 운명을 가르는 판단형 객관식을 풀어내는
텍스트 어드벤처 게임입니다.

## 🎮 플레이

https://soonhakahn.github.io/war-odyssey/

아이폰/모바일 브라우저에서 링크를 눌러 바로 플레이할 수 있습니다.

## 🕹️ 게임 방법

- 각 성채마다 제시되는 딜레마에서 선택지를 고르세요.
- 선택에 따라 **병력 / 식량 / 사기 / 명예** 스탯이 변동합니다.
- 병력이나 사기가 0이 되면 여정이 끝납니다.
- 일곱 성채를 모두 통과하면 최종 스탯에 따라 여러 결말 중 하나를 맞이합니다.

## 🔮 Jev 예언자 (선택 사항)

Jev API 키를 입력하면 각 판단 앞에서 Jev AI의 확률 기반 조언을 받을 수 있습니다.
키 없이도 게임은 완전히 플레이할 수 있으며, 키는 브라우저에만 저장됩니다.

## 📁 구성

- `index.html` — 게임 본체 (단일 파일)
- `.github/workflows/deploy.yml` — GitHub Pages 자동 배포
